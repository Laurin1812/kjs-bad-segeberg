      Hund / Wurf anbieten

      Startseite/Hundebörse/Hund / Wurf anbieten

      Füllen Sie das Formular aus, um einen Hund oder Wurf einzustellen. Ihre Anzeige wird vor der Veröffentlichung durch die Kreisjägerschaft geprüft.

      Bitte prüfen Sie folgende Angaben:

        1. Art der Anzeige *

        2. Grunddaten

        Bitte geben Sie einen Titel für die Anzeige an.

        Bitte geben Sie die Rasse an.

        Bitte geben Sie das Geburtsdatum an.

        Bitte geben Sie das Geschlecht an.

        Bitte geben Sie das Wurfdatum an.

        3. Preis & Standort

        Bitte geben Sie eine gültige 5-stellige PLZ an.

        Bitte geben Sie den Ort an.

        Es wird nur der ungefähre Standort veröffentlicht, keine genaue Adresse.

        4. Jagdliche Informationen (optional)

        5. Abstammung (optional)

        Vorschläge aus bereits verwendeten Zuchtverbänden oder eigenen Namen eingeben.

        6. Beschreibung *

        Bitte geben Sie eine Beschreibung an.

        7. Bilder *

        Mindestens 1, maximal 10 Bilder. Mehrere Bilder können gleichzeitig ausgewählt werden. Das erste Bild ist das Hauptbild – per Ziehen (Drag & Drop) können Sie die Reihenfolge ändern. Erlaubte Formate: JPG, PNG, WebP.

        0 / 10 Bilder ausgewählt

        Es können maximal 10 Bilder hochgeladen werden. Überzählige Bilder wurden nicht hinzugefügt.

        Bitte laden Sie mindestens ein Bild hoch.

        8. Anbieter / Kontakt

        Bitte geben Sie den Namen des Anbieters an.

        Bitte geben Sie eine gültige E-Mail-Adresse an.

        9. Hinweise & Zustimmung

        Bitte bestätigen Sie die Richtigkeit Ihrer Angaben.

        Bitte stimmen Sie der Datenverarbeitung zu.

        Ihre Anzeige wird erst nach Prüfung durch die Kreisjägerschaft veröffentlicht.

        Formular erfolgreich geprüft

        Die technische Übermittlung der Anzeige wird aktuell vorbereitet. Ihre eingegebenen Daten wurden in diesem Test nicht versendet.
