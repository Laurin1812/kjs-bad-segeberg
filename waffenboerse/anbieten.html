Anzeige aufgeben

Hier können Sie eine Anzeige für die Waffenbörse der Kreisjägerschaft Segeberg einreichen. Die Anzeige wird vor der Veröffentlichung geprüft und ist erst nach Freigabe öffentlich sichtbar.

Bitte beachten Sie die gesetzlichen Vorgaben für den Erwerb und die Veräußerung von Waffen, Munition und erlaubnispflichtigen Gegenständen.

Bitte prüfen Sie folgende Angaben:

    1. Grunddaten

    Bitte geben Sie einen Titel für die Anzeige an.

    Bitte wählen Sie eine Kategorie aus.

    Bitte geben Sie den Hersteller an.

    Bitte je Kaliber ein eigenes Feld verwenden, z. B. „7x65R“, „12/70“, „5,6x52R“ (nicht durch Komma trennen, da Kaliber selbst Kommas enthalten können).

    Bitte wählen Sie den Zustand aus.

    2. Preis & Versand

    Bitte wählen Sie eine Preisart aus.

    Bitte geben Sie einen gültigen Preis an.

    Bitte geben Sie an, ob Versand möglich ist.

    3. Standort

    Bitte geben Sie eine gültige 5-stellige PLZ an.

    Bitte geben Sie den Ort an.

    4. Erwerbsberechtigung

    Bitte wählen Sie „Ja“, wenn für den angebotenen Gegenstand eine gesetzliche Erwerbsberechtigung erforderlich ist.

    Bitte wählen Sie eine Option aus.

    Bitte prüfen Sie, ob für diesen Gegenstand tatsächlich keine Erwerbsberechtigung erforderlich ist.

    5. Beschreibung *

    Bitte geben Sie eine Beschreibung an.

    6. Bilder *

    Mindestens 1, maximal 10 Bilder. Mehrere Bilder können gleichzeitig ausgewählt werden. Das erste Bild ist das Hauptbild – per Ziehen (Drag & Drop) können Sie die Reihenfolge ändern. Erlaubte Formate: JPG, PNG, WebP, max. 8 MB pro Bild.

    0 / 10 Bilder ausgewählt

    Es können maximal 10 Bilder hochgeladen werden. Überzählige Bilder wurden nicht hinzugefügt.

    Bitte laden Sie mindestens ein Bild hoch.

    7. Kontaktdaten

    Bitte geben Sie Ihren Namen an.

    Bitte geben Sie eine gültige E-Mail-Adresse an.

    8. Zustimmung & Absenden

    Bitte bestätigen Sie diese Angabe.

    Bitte stimmen Sie der Verwendung Ihrer Kontaktdaten zu.

    Ihre Anzeige wird erst nach Prüfung durch die Kreisjägerschaft veröffentlicht.

    Vielen Dank!

    Ihre Anzeige wurde erfolgreich zur Prüfung eingereicht.
    Die Anzeige ist noch nicht öffentlich sichtbar. Nach Prüfung durch die Kreisjägerschaft wird sie freigegeben oder bei Rückfragen entsprechend bearbeitet.
